
## Backend Code Execution Rule
Whenever dealing with backend code (e.g., API routes in the `api/` directory), DO NOT write the code directly. Instead:
1. Output the backend code in the chat.
2. Provide detailed explanations (what the code is doing, backend concepts to check out).
3. Define the frontend contract (what the frontend expects the API to be like).
4. Instruct the user to copy/paste and write it themselves.
Note: You may continue to implement frontend tasks directly.
